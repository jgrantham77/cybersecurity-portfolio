# MegaQuagga Penetration Test

## Overview

Performed a structured penetration test against a simulated enterprise web application to validate previously identified vulnerabilities and assess their potential impact. This project demonstrates a complete penetration testing workflow, including reconnaissance, service enumeration, vulnerability validation, controlled exploitation, post-exploitation analysis, and remediation planning.

---

## Objectives

* Validate previously identified vulnerabilities
* Assess exploitability within a controlled lab environment
* Demonstrate potential business impact
* Develop prioritized remediation recommendations
* Produce executive and technical reporting

---

## Methodology

1. Reconnaissance
2. Service Enumeration
3. Vulnerability Research
4. Vulnerability Validation
5. Controlled Exploitation
6. Post-Exploitation Analysis
7. Reporting and Remediation

---

## Key Findings

* HTTPS was not configured on the target web application.
* Apache, PHP, and WordPress were outdated.
* Multiple WordPress plugins required updates.
* The Social Warfare plugin was identified as vulnerable to CVE-2019-9978.
* Controlled exploitation successfully validated unauthorized access within the approved lab scope.
