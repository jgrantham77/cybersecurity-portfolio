## About Me

After nearly two decades leading teams and managing multimillion-dollar operations, I've built a career around solving complex problems, mitigating risk, improving processes, and protecting assets. Today, I'm applying that experience to cybersecurity, where those same principles drive effective threat detection, incident response, and security operations.

Through the TripleTen Cybersecurity Program and extensive home lab development, I've gained hands-on experience with:

* SIEM monitoring, log analysis, and threat detection using Splunk and Wazuh
* Incident response workflows, alert triage, and security investigations
* Linux administration, command-line operations, and system hardening
* pfSense firewall configuration and network troubleshooting
* Python scripting for automation and data analysis

My background as a Branch Manager and Loss Prevention Manager provided extensive experience in operational risk management, compliance, investigations, asset protection, and leadership. These skills translate directly to cybersecurity, where identifying threats, analyzing risk, and protecting critical assets are essential.

I approach cybersecurity with the same mindset that fueled my success in leadership roles: stay curious, think strategically, continuously improve, and never stop learning.

I am currently pursuing opportunities as a Cybersecurity Analyst, SOC Analyst, or Security Operations professional, where I can contribute, continue developing my technical skills, and help organizations strengthen their security posture.
